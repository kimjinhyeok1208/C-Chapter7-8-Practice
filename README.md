## 📝 Practice Problems
### 1️⃣ Number Pattern Printing
정수 `n`을 입력받아 다음과 같은 숫자 패턴을 출력하는 프로그램을 작성한다.

**입력 예**

n = 5

**출력 예**

1

12

123

1234

12345

**학습 포인트**

- `for` 반복문
- 함수 정의 및 호출
- 반복 구조 이해
------------------------------------------------------------------------------------------------------------------------------------------
### 2️⃣ Count Prime Numbers in a Range
두 정수 `a`, `b`를 입력받아  
`a` 이상 `b` 이하에 존재하는 **소수의 개수**를 출력한다.

**입력 예**

10 30

**출력 예**

Number of primes: 6

**학습 포인트**
- 중첩 반복문
- 소수 판별 로직
- 함수 분리 설계

------------------------------------------------------------------------------------------------------------------------------------------

### 3️⃣ Sum and Average Calculation
양의 정수를 반복해서 입력받다가 `0`이 입력되면 종료하고,  
입력된 값들의 **합과 평균**을 계산하여 출력한다.  
(`0`은 계산에서 제외)

**입력 예**

5 10 15 0

**출력 예**

Sum = 30

Average = 10.00

**학습 포인트**
- `while` 반복문
- 입력 종료 조건 처리
- 함수 반환값 활용
- 평균 계산 시 형 변환
